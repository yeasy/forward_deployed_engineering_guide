# 附录

附录用于承接全书的查阅型内容。正文以能力和交付流程为主，附录则集中整理术语、参考资料和工具生态，便于读者在阅读、复盘和项目实践中快速定位。

附录不替代正文，也不把工具清单当成方法论。FDE 项目中真正重要的是判断问题、建立系统边界、交付可运行结果和沉淀可复制能力；工具只是在特定约束下实现这些目标的手段。

## 附录使用方式

阅读正文时，遇到第一次出现的缩写、工程术语或工具名称，可先查阅[术语表](glossary.md)。需要验证事实来源时，可查阅[参考文献](references.md)；核对第十四章案例声明时，使用[声明账本](claim_ledger.md)；判断书中某类外部事实是否已经过期、以及该回哪个官方入口复核时，使用[快变事实核验表](volatile_facts.md)。两张表分工不同：声明账本记录「某条证据在某日核验过、不能外推到哪里」，是不过期的历史记录；核验表记录「哪一类外部事实会变、多久该回头看一次」，是会过期并触发构建失败的时钟。需要为现场交付选择工具时，可参考[工具索引](tools.md)，但应结合客户环境、权限边界、团队能力和合规要求做最终判断。需要把发现、架构、上线、运维和接管材料落成可复查产物时，可直接使用[交付证据包模板](templates.md)，再用[综合实战](capstone.md)完成从 Discovery 到客户接管的一体化验收。
